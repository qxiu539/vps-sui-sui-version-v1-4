# S-UI VPS 辅助脚本

这是一个给 VPS 使用的菜单脚本，帮你做三件事：

- 安装 S-UI 面板 `v1.4.1`
- 生成 S-UI 面板的 SSH 本地转发连接命令
- 检测 Reality 目标域名的 TLS 1.3 连接延迟

## 风险提示

安装 S-UI 面板会从 GitHub 下载并执行远程脚本，可能会修改 VPS 的服务、端口和系统配置。脚本里已经加了二次确认，只有输入 `YES` 才会开始安装。

Reality 域名检测只会测试域名连通性，不会修改系统。

## 使用方法

把 `install_sui_panel.sh` 上传到 VPS 后运行：

```bash
chmod +x install_sui_panel.sh
./install_sui_panel.sh
```

成功标志：你会看到菜单：

```text
S-UI VPS 辅助脚本
1) 安装 S-UI 面板
2) 生成 SSH 本地转发命令
3) Reality 目标域名检测
4) 一键流程：测速 -> 可选安装 -> 生成连接命令
0) 退出
```

## 连接 S-UI 面板

如果你的 VPS IP 是 `38.207.171.104`，面板端口是 `2095`，脚本会生成类似命令：

```bash
ssh -L 2095:127.0.0.1:2095 root@38.207.171.104
```

在你自己的电脑终端运行这条命令，并保持 SSH 不要断开。

成功标志：浏览器打开下面地址能看到 S-UI 面板：

```text
http://127.0.0.1:2095
```
